# 实时词云 · Live Word Cloud

一个纯前端的实时词云工具：打开页面 → 输入文字 → 词云即时生成，并支持多人实时协作。

🔗 在线地址：https://dt2027.github.io/wordcloud/

## 功能

**词云**

- **实时生成**：输入即更新（250ms 防抖），无需点击
- **中文分词**：内置 9000 词常用词表 + PMI 内聚度 + 上下文自由度 + 重叠冲突消解，
  能正确切出「新能源汽车」「插电式混合动力」这类长词，不会满屏碎片
- **自适应布局**：网格占用 + 椭圆螺旋排布，手机小屏也能铺满
- **完全本地**：分词与渲染全在浏览器完成，内容不上传服务器
- 5 套配色、词数上限可调、悬停显示词频、点击复制词语

**多人协作**

- 点「开启协作」生成房间，复制链接邀请伙伴；也可以直接打开带 `#r=房间号` 的链接加入
- 房间内所有人编辑**同一份共享文档**，任何人的输入都会实时同步给其他人
- 基于 **Yjs CRDT** 做冲突合并：多人同时改同一处也不会互相覆盖，编辑自动收敛
- 词云基于共享内容实时重算，在线成员列表实时显示
- 晚加入 / 掉线重连的成员会自动追平进度（retained 状态 + 周期性全量广播）

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构与样式 |
| `app.js` | 主逻辑：分词、词云渲染、协作界面 |
| `collab.js` | 协作层：Yjs 共享文档 + MQTT 同步协议 |
| `mqtt-lite.js` | 极简 MQTT 3.1.1 客户端（WebSocket 传输，~7KB，零依赖） |
| `vendor/yjs.bundle.mjs` | Yjs 打包产物（esbuild，93KB，离线可用） |
| `dict.js` | 中文常用词表（9000 词，jieba 词典高频子集） |

## 同步协议

静态网站没有服务端，协作通过公共 MQTT over WebSocket 广播完成：

| 主题 | 作用 |
| --- | --- |
| `wc/<room>/doc` | retained，完整文档状态（base64），保证后加入者追平 |
| `wc/<room>/live` | 增量更新，或新成员加入时的状态请求响应 |
| `wc/<room>/req` | 新成员加入时广播的状态请求 |
| `wc/<room>/p/<id>` | retained，在线状态 `{name, ts}` |

默认依次尝试 `broker.emqx.io` → `broker.hivemq.com` → `test.mosquitto.org`，
任一可用即可；也可在 `collab.js` 的 `DEFAULT_BROKERS` 里换成自己的 MQTT 服务，
内容就不会再经过第三方服务器。

## 本地运行

```bash
python -m http.server 8777
# 浏览器打开 http://localhost:8777/
```

## 技术说明

- 无框架、无构建、无外部 CDN 依赖，离线可用
- Canvas 2D 绘制，按 devicePixelRatio 适配高分屏
- 排布算法：网格（6px）占用标记 + 预生成椭圆螺旋路径（约 12000 个候选位置），
  典型渲染耗时 30~90ms
- 协同编辑的冲突消解交给 Yjs CRDT，本地改动与远端改动走同一条 diff 通路，
  光标位置用 Yjs 相对位置保持
